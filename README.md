# CyberDork OSINT Suite v7.0 (Ultimate Matrix Edition)

CyberDork OSINT Suite v7.0 is a multi-engine search dorking, 700+ extension reconnaissance, custom query builder, interactive CLI terminal, and target intelligence portal.

## 🚀 Key Features

1. **Dashboard & Quick OSINT Radar**: Live Matrix canvas, statistics cards, and pre-filled target reconnaissance.
2. **CyberDork Pro Engine**: Categorized dork collections with single and multi-engine launching capabilities.
3. **700+ File Extension Hub**: Categorized index of 700+ file extensions for google filetype search execution.
4. **Visual Dork Builder & Hash Identifier**: Custom GUI builder for advanced dork syntax and hash pattern recognition.
5. **Interactive Cyber Terminal CLI**: Command-line simulation overlay for quick query triggers.
6. **Local Auth & History Manager**: User login session management and search target exports (JSON/CSV).

## 🛠️ Deployment Instructions

### Deploy to Vercel / Netlify / GitHub Pages

- Import the repository on Vercel, Netlify, or GitHub Pages.
